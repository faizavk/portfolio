# faizavk.site

Personal site for Faiza V K. React and Vite, with plain CSS. Same front-end setup as Smart Campus. No component library.

```bash
npm install
npm run dev
```

Open the URL Vite prints. `npm run build` writes `dist/`. Any static host needs to serve `index.html` for unknown paths. `vercel.json` and `public/_redirects` already do that for Vercel and Netlify.

The resume PDF linked from the nav is `public/Faiza_VK_Resume.pdf`, generated by `../build_resume.py`.
